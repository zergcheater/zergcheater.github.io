💡 What This Application Is

Arabic is spoken by hundreds of millions of people, and the number of AI tools built for it grows every week. The problem is finding them. Projects are scattered across research pages, code repositories, chat threads, and newsletters, and most of them are described in technical language that leaves everyday users guessing.

arabic-ai-atlas solves that by turning the Arabic AI ecosystem into something you can actually look at. It works as three things at once: a map that shows how tools relate to each other, a list that you can read top to bottom, and a skill your agent can install so your AI assistant can answer questions about the ecosystem on your behalf.

You do not need to know how to code to use it. If you can open a web page or a folder on Windows, you can use this atlas. It is designed for researchers, translators, content creators, product managers, students, and anyone curious about what Arabic AI can do today.

✨ What You Get

Everything in the atlas is organized so you can move from a broad question to a specific answer in a few clicks. The main pieces are:

  • A curated directory. Tools for Arabic text, speech, translation, and language models, grouped by the job they do rather than by the company that made them.
  • A visual map. See how categories connect, from raw text processing to speech recognition to generation, so you understand where a tool fits before you commit to it.
  • Plain-language descriptions. Each entry explains what the tool does, who it is for, and what kind of Arabic it handles.
  • An agent skill. A ready-made package your AI assistant can install so it can look up atlas entries and answer questions with the same information you see.
  • An MCP server. A standard connector that lets compatible AI tools read the atlas directly as a live source of knowledge.
  • Regular updates. New projects are added as the Arabic AI field grows, so the atlas does not go stale after a month.

🤖 Using It as an Agent Skill

One of the most useful things about this atlas is that it does not have to stay on a web page. It can be installed as a skill for an AI assistant, which means your assistant stops guessing about Arabic AI tools and starts reading from the same curated list you do.

This matters because Arabic AI is a fast-moving field with a lot of incomplete or outdated information. When your assistant has the atlas available, the answers it gives you come from a maintained source rather than from memory. You can ask it which speech recognition tool handles Gulf dialects, which text-to-speech engine supports Modern Standard Arabic, or which language model is small enough to run on modest hardware.

The atlas is also packaged as an MCP server, which is a widely supported way to give AI tools access to outside information. If your assistant supports that standard, you can connect the atlas once and keep it available for every conversation.

No. The atlas is built for readers, not just developers. The optional agent skill and MCP server are there for people who want deeper integration, but the core experience is simply browsing and reading.

Yes. The download page linked above provides the application, and the steps in the Getting Started section are written with Windows users in mind.

How often is it updated?

The project is actively maintained. New Arabic AI tools are added as they appear, and corrections are welcome from anyone who spots an error or a missing entry.

📄 Contributing and License

The atlas improves when people who work with Arabic AI share what they know. If you have built a tool, use one daily, or notice that an entry is out of date, the project welcomes your input. Suggestions are handled through the repository, where you can open an issue or propose a change directly.
